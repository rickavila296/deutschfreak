# Content review

The Curriculum Specification lists each lesson's new language, but not every sentence. When Claude Code composes an example, a dialogue line or an exercise item from that language, it logs the item here, one file per unit (for example `A1.1.U01.md`), so the teacher can review it (PRD-NFR-005, PLAN-DEC-13).

| Content file | Code | German | English | Built from | Teacher verdict |
|---|---|---|---|---|---|

The teacher's verdict is one of: ok · change to … · remove. Changes go back into the content files, and the import is run again.
