1. components/lesson/stage-rail.tsx:102: Continue went to stage + 1 over nine stages, so a stage missing from the data gave a blank area with no Continue. FIX: navigation runs over the stages present; the lesson opens at the first one; a missing stage shows on the rail as "not available" and is never selected or continued to. TEST: lesson without stages 1 and 3.
2. components/map/open-part-from-hash.tsx:7: decodeURIComponent threw on /learn#%E0 and the error page replaced the map. FIX: an undecodable fragment is ignored. TEST: '#%E0' does not throw and opens nothing.
3. lib/api.ts + pages: `dynamic = 'force-dynamic'` turned the 5-minute fetch cache off. CONFIRMED in the Next 16 docs shipped with the package (caching-without-cache-components: force-dynamic sets every fetch to `{ cache: 'no-store', next: { revalidate: 0 } }`). FIX: pages call `await connection()` (render per request, build never needs the API) and keep `next.revalidate: 300`. TESTS: no file in src/app uses force-dynamic, fetchCache or revalidate = 0; every page calls connection(). MEASURED: from a cold cache, 6 page loads made 1 API request.
4. lib/api.ts:31: any 404 became "Page not found", so a wrong NEXT_PUBLIC_API_URL would show 404 site-wide. FIX: null only for the API's own error body with the expected code (`lesson_not_found`, `level_not_found`, decision 0015); any other 404 is an ApiRequestError and shows the load-error page. TEST: plain-text 404, `not_found` route 404, and the wrong code all throw.
5. lib/api.ts:33: response.json() was not guarded, so a non-JSON 2xx (e.g. a Vercel protection page) threw a raw error. FIX: a body that is not JSON is an ApiRequestError. TEST: HTML 200 throws ApiRequestError for both calls.
6. components/map/german-map.tsx:35: the part h2 was inside <summary>, which assistive technology exposes as a button, dropping the heading. FIX: each part is a <section> (id a1-N, labelled by its h2) with title, statement, tag and course-page copy outside the collapsible; only "Units and lessons of A1.N" collapses. TEST: no heading inside a summary; each part is a labelled region.
7. components/lesson/stage-rail.tsx:160: aria-label on a role-less span is ignored, so "current stage" / "not reached yet" were not announced. FIX: stage number and state are visually hidden text inside each step; no aria-label in the rail. TESTS: no [aria-label] in the rail; buttons are found by their accessible name ("Stage 1: Objective, reached"); tests no longer use getByLabelText.
8. components/lesson/stages.ts:19: the translation rule ignored the part. FIX: `translationMode(unitCode, stage)`: shown in A1.1, tap-to-reveal (native <details>, "Show translation") from A1.2, hidden in stages 7 and 9 everywhere (TRD-FE-11, PRD FR-023).
